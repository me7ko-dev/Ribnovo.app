# Рибново

Уеб приложение (PWA) за село Рибново: аларми, събития и новини.
Инсталира се на началния екран на Android и iPhone и праща известия.

**Технологии:** Next.js · Supabase (база данни и вход) · Web Push

## Фази

| Фаза | Какво | Състояние |
| --- | --- | --- |
| 1 | Основа: структура, база данни, начален екран с примерни данни | ✅ |
| 2 | Вход с телефон или имейл, профили и роли, екран „Профил“ | |
| 3 | Екрани „Аларми“ (с превключватели) и „Събития“ (седмичен календар) | |
| 4 | „Публикувай“, одобрение от администратора, „Докладвай“ | |
| 5 | Инсталиране на началния екран (PWA) | |
| 6 | Web Push известия, дори когато приложението е затворено | |
| 7 | Пускане за селото: домейн, последни проверки | |

## Структура

```
src/app/              екраните (page.tsx = една страница)
  page.tsx            Начало
  alarmi/             Аларми
  sabitiya/           Събития
  publikuvay/         Публикувай
  profil/             Профил
src/components/       части от екраните (карти, меню)
src/lib/              данни, дати, връзка със Supabase
supabase/migrations/  структурата на базата данни (SQL)
supabase/seed.sql     примерни данни
```

## Роли

- **Администратор** — одобрява публикации, дава права.
- **Проверен профил** (кметство, училище) — пуска аларми, които веднага пращат известие.
- **Жител** — публикува новини и обяви, които минават одобрение; може да докладва.

## Пускане на компютър (за разработка)

```bash
npm install
cp .env.example .env.local   # по желание — без него има примерни данни
npm run dev                  # отворете http://localhost:3000
```

## База данни

В Supabase → **SQL Editor** пуснете поред:

1. `supabase/migrations/0001_init.sql` — таблици, роли и правила за достъп
2. `supabase/seed.sql` — примерни данни (по желание)
