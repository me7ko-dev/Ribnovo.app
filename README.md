# Рибново

Уеб приложение (PWA) за село Рибново: аларми, събития, новини и обяви.
Инсталира се на началния екран на Android и iPhone и праща известия, дори когато е затворено.

**Технологии:** Next.js 16 · Supabase (база данни, вход, снимки) · Web Push · Tailwind CSS

## Какво може

- **Начало** — активната важна аларма (оранжево), „Предстои“ (събития), новини като във Facebook.
- **Новини и обяви** — снимки, харесвания, коментари, „Докладвай“.
- **Аларми** — активни и приключили; превключватели за известията: Спешни (винаги), Ток и вода, Път и сняг, Събития, Възпоменания, Обяви.
- **Събития** — седмичен календар и списък.
- **Публикувай** — новина, събитие, обява; аларма (само проверени профили).
- **Профил** — регистрация и вход с имейл или телефон, снимка, „Моите публикации“, забравена парола.
- **Администрация** — одобряване, сигнали, даване на права.

## Роли

| Роля | Може |
| --- | --- |
| **Администратор** | всичко; одобрява публикации; обработва сигнали; дава права |
| **Проверен профил** (кметство, училище) | пуска аларми с известие веднага; публикува без одобрение |
| **Жител** | публикува новини, събития и обяви — след одобрение; харесва, коментира, докладва |

## Настройка (веднъж)

### 1. Supabase
1. Нов проект на [supabase.com](https://supabase.com) (регион Frankfurt).
2. **SQL Editor** → пуснете поред: `supabase/migrations/0001_init.sql`, `supabase/migrations/0002_social.sql`, по желание `supabase/seed.sql`.
3. **Authentication → URL Configuration**: *Site URL* = адресът на сайта (напр. `https://ribnovo.vercel.app`); в *Redirect URLs* добавете `https://ribnovo.vercel.app/**`.
4. **Authentication → Sign In / Providers → Email**: по желание изключете *Confirm email* (вграденият имейл на Supabase праща само няколко имейла на час — за повече настройте собствен SMTP, напр. Resend).
5. Вход с телефон (по желание, платено): **Authentication → Sign In / Providers → Phone** → включете и въведете данни от SMS доставчик (Twilio, Vonage…).

### 2. Ключове (Vercel → Settings → Environment Variables)
Вижте `.env.example`. След промяна: **Deployments → ⋯ → Redeploy**.

### 3. Първи администратор
Регистрирайте се в приложението, после в Supabase → **SQL Editor**:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'вашия@имейл.bg');
```

Оттам нататък давате права от приложението: **Профил → Администрация → Хора**.

## Разработка на компютър

```bash
npm install
cp .env.example .env.local   # попълнете ключовете
npm run dev                  # http://localhost:3000
```

С локален Supabase (нужен е Docker): `npx supabase start`, после сложете показаните URL и ключове в `.env.local`.

```
src/components/          части от екраните

public/sw.js             service worker (известия, офлайн)
supabase/migrations/     структурата на базата
supabase/seed.sql        примерни данни
```
